## Brand & Style
The design system reflects technical rigor, architectural clarity, and high-craft digital execution. Geared toward engineering leaders, founders, and technical recruiters, the aesthetic rejects superficial decoration in favor of structural elegance, high readability, and deliberate micro-interactions.

The visual style blends **Technical Minimalism** with **Tonal Glass Layers**. It delivers a high-density, developer-centric feel through crisp 1px borders, monospace accenting, subtle background grids, and restrained teal accents. The atmosphere is quiet, confident, and utilitarian—presenting engineering leadership through systematic organization and polished hierarchy.

## Colors
The color palette anchors on deep slate foundations punctuated by surgical teal accents, tuned specifically for WCAG AAA/AA readability across high-contrast environments.

- **Surface Elevation 1 (Card/Container):** `#111827` (Layered dark slate)

## Typography
The system employs a three-tier typographic engine:
- **Display & Headings:** `Geist` provides tight geometric clarity and a neutral modernist silhouette with negative letter tracking for large sizes.
- **Body & Longform:** `Inter` handles continuous reading with tall x-height and optical legibility down to 13px.
- **Syntax, Badges & Labels:** `JetBrains Mono` grounds technical metrics, metadata chips, terminal blocks, and dates in developer tooling vernacular.

Maintain strict baseline alignment: longform paragraphs should not exceed 68 characters per line to guarantee optimal scanning efficiency.

## Layout & Spacing
The layout follows a 12-column fluid grid system bounded by a maximum content width of `1200px` (`max-w-6xl` in Tailwind conventions), centering content within expansive ambient canvas margins.

### Breakpoints & Adaptation
- **Mobile (< 640px):** Single-column stack. Outer margin collapses to `1rem`, card internal padding to `space-md` (16px), eliminating nested horizontal gutters.
- **Tablet (641px - 1024px):** 6-column grid with `1.5rem` gutters. Project cards reflow to a 2-column layout; secondary metrics collapse into dual-column key-value pairs.
- **Desktop (> 1024px):** Full 12-column grid. Sidebar navigation or sticky bio summaries occupy 4 columns, while main narrative streams and featured showcases occupy 8 columns.

Spacing maintains an 8-point rhythm, using `0.25rem` (4px) increments solely for micro-alignments, tag paddings, and inline icon offsets.

## Elevation & Depth
Depth relies on **Tonal Layers** paired with **Micro-Borders** rather than heavy drop shadows, emulating the look of refined IDE and developer console surfaces.

### Surface Tiers
1. **Base Surface (Z-0):** Matte background (`#0B0F14` dark / `#F8FAFC` light).
2. **Card Layer (Z-1):** Flat `#111827` dark fill backed by a single 1px solid border (`#1E293B`). Shadow is invisible or subtly ambient: `0 1px 2px 0 rgba(0, 0, 0, 0.4)`.
3. **Floating Overlays & Popovers (Z-2):** `#161F2E` with 12px backdrop blur (`backdrop-blur-md`), 1px border (`#334155`), and a calibrated teal-tinted shadow: `0 12px 32px -8px rgba(0, 0, 0, 0.6), 0 0 0 1px rgba(20, 184, 166, 0.08)`.

Hovering interactive cards shifts the border from `#1E293B` to `#14B8A6` at 40% opacity, paired with an ultra-subtle directional lift of -2px.

## Shapes
Component geometry utilizes an intentional 10px to 12px radius profile, avoiding both stark brutalist corners and toy-like pill bubbles.

- **Primary Cards & Modals:** Standardized to `12px` (`rounded-xl` in standard Tailwind configs).
- **Buttons, Inputs & Code Badges:** Standardized to `8px` (`rounded-lg`) for a compact, tool-like feel.
- **Status Indicators & Micro-Chips:** Pill-shaped (`9999px`) exclusively for active availability indicators and online state pings.

## Components

### Buttons
- **Primary:** Background `#0D9488`, high-contrast text `#F8FAFC`, radius `8px`, font `Geist Medium 14px`. Hover triggers transition to `#14B8A6` with subtle inner highlight (`box-shadow: inset 0 1px 0 rgba(255, 255, 255, 0.2)`).
- **Secondary / Outline:** Background transparent, 1px border `#1E293B`, text `#F8FAFC`. Hover applies background `#111827` and border `#334155`.
- **Ghost / Link:** Text `#94A3B8`, no border, inline transition to `#14B8A6` on hover with underline accent.

### Chips & Syntax Badges
- **Tech Stack Badges:** Rendered in `JetBrains Mono` 12px. Background `rgba(13, 148, 136, 0.1)`, text `#14B8A6`, 1px border `rgba(20, 184, 166, 0.2)`. Padding: `4px 10px`. Radius: `6px`.
- **Status Chip ("Available for Hire"):** Monospace 11px uppercase label with a pulsing 6px emerald dot (`#10B981`) on the left, encased in a low-opacity dark charcoal frame.

### Project Cards
- Elevated `#111827` surface container, 1px border `#1E293B`, internal padding `space-lg` (24px).
- Top: Category or architecture tags in monospace.
- Middle: `headline-sm` project title in Geist, followed by muted Inter body description.
- Bottom: Live link, repository link, and stacked dependency tags.
- Interaction: Smooth border color transition (`duration-200`) and slight inner gradient illumination (`radial-gradient` centered on mouse position where possible).

### Form Inputs
- Background `#0B0F14`, 1px border `#1E293B`, text `#F8FAFC`, placeholder text `#475569`.
- Height: 42px. Radius: `8px`. Padding: `0 14px`.
- Focus State: Border color transitions directly to `#14B8A6` with a `0 0 0 1px #14B8A6` ring. Outline removed.

### Checkboxes & Radios
- Size: 18px by 18px. Box border: `#334155` on `#0B0F14`.
- Checked: Fill `#0D9488` with sharp white SVG icon check. Radius `4px` for checkboxes, circular for radios.

### Code & Terminal Blocks
- Background `#0B0F14`, bordered with `#1E293B`, containing an upper header bar featuring simulated window controls (`#334155` dots) and a title in `JetBrains Mono`.
- Code lines set with line numbers in `#475569` and syntax highlights using teal (`#14B8A6`), sky blue (`#38BDF8`), and stone slate (`#E2E8F0`).
